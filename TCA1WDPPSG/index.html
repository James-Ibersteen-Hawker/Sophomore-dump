Honors Web Design

TCA1 Study Guide

(Use w3schools.com as a reference)

  1. What is HTML?
        HyperText Markup Language
  2. Who invented HTML? When?
        It was invented by Tim Berners-Lee in 1993.
  3. What is the purpose of the <html> tag?
        It states that whatever is inside of it is HTML.
  4. Why was CSS developed?
         To add color and the ability to StYle HTML code to look more presentable.
  5. What is the purpose of the <!DOCTYPE html> tag?
        It states that what follows is an HTML document.
  6. What goes in the <head> tag?
        The <title>, the <link> to style.css, and any <meta>tags.
  7. What is the purpose of the <title> tag and where does it go?
        The purpose of the <title> tag is to determine what to display on the tab name. It goes inside of the <head> tag.
  8. List some elements that you would put inside the <body> tag.
    • <ul>
    • <a>
    • <h1>
    • <h2>
    • <script>
    • <iframe>
    • <div>
    • <hr>
  9. List the heading tags in order from largest to smallest:
    • <h1>
    • <h2>
    • <h3>
    • <h4>
    • <h5>
    • <h6>
  10. Describe how to make one word in a sentence bold? Not using CSS.
        It is done using the <strong> tag.
  11. Describe how to make the background of a div red? Using CSS.
        div {
        background-color: #ff0000;
        }
  12. What is index.html? Why can you not rename it?
        Because index.html is the source page for the html document that the browser looks for upon opening the page.
  13. What is UTF-8?
        The reference name for the current version of unicode.
  14. How can I have two paragraph tags but style each of them differently using CSS?
        Using either class=”” or id=””, and then addressing it either .classname or #idname.
  15. What does href mean?
        Hyperlink REFerence.
  16. What is the purpose of alt text in an image tag?
        So that a screen-reader or a program which cannot display images has alternate text to display instead of the image.
  17. When would you use a <br> tag? When would you use an <hr> tag?
        You would use a <br> tag to create an enter line in a passage of text and you would use an <hr> tag to create a horizontal line across the page to help split up the content.
  18. How do you format an image anchor tag?
           There are two components to this.
         First, the image tag, which looks like this:
            <img src=”image_file.filetype”>
           The second component is the anchor tag, or the hyperlink. It is formatted like this:
            <a href=”link”>insert linked element</a>
  19. What is the difference between serif and sans-serif fonts?
        Serif fonts have small hooks, or ‘fangs’, at the ends of letters, and these can be seen particularly on letters like the S or the T, where they droop downwards from the ends. A sans-serif font does not have these ‘fangs’.

    List 5 google fonts that are serif:
    • Graduate
    • Playfair Display
    • Cinzel
    • IM Fell English
    • Baskervville
     List 5 google fonts that are sans-serif:
    • Aclonica
    • Fira Sans
    • Oswald
    • Raleway
    • Roboto
  20. What are some reasons for adding comments to our code? What does a comment look like in html? What does a comment look like in CSS?
        Comments help to organize your code by clearly labeling the different components. A comment in HTML looks like <!-- this -->. A comment in CSS looks like /* this */.
  21. What is a hyperlink? And how do you create a button that is linked to another website in html?
        A hyperlink is a link that can bring you either to another website or to another page/div in the same website. In order to create a link in HTML, you need to use:
        <a href=”link”>insert linked element</a>
  22. What is the difference between JPEG and PNG?
        A JPEG is a small, highly compressed, lossy, and alpha-channel-less image format, intended for easy sending and transfer.
        A PNG is a larger, almost not-compressed, alpha-supporting image format intended for display.
  23. What are the html tags used to build a table? Give an example of when you might need to use a table on a website.
    • <table>
    • <tr>
    • <td>insert table value</td>
    • </tr>
    • </table>
        You might need a table to organize your website, or to place elements into given spots, or as a table of values to be displayed.
  24. What are the html tags used to build a list? Numbered and Bulleted?

    <!-- Bulleted List-->

    <ul>
    <li></li>
    </ul>

    <hr>

    <!-- Numbered List-->

     <ol>
    <li></li>
    </ol>
  25. What is an iFrame tag used for?
        The <iframe> tag is used for embedding external elements inside of the html document.
  26. What is the CSS Box Model?
        The CSS Box Model is a physical illustration of margin, border, and padding, displayed as a box. The air outside the box is the margins, the box itself is the border, and the space between the box and the elements inside of it is the padding.
